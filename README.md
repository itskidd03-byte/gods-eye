# God's Eye

The living world of Johan, published as an installable web app:

https://itskidd03-byte.github.io/gods-eye/

The game is built in the `Lost` repository under `gods-eye/` and published to
`docs/gods-eye/`. A workflow in this repository copies that build and deploys it
here, so this URL always serves the latest published world.

To refresh the published copy, run the **Publish God's Eye** workflow or push to
this repository.
